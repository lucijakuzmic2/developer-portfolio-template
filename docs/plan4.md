# Plan 4 — Add hero section to index.html

## Goal

Add a semantic and accessible hero section as the primary introductory content of the portfolio homepage.

## Why

- Communicates the site purpose immediately
- Provides a clear call to action
- Establishes visual hierarchy and layout structure
- Follows common portfolio and industry design patterns

## Scope

Files to modify:

- index.html

## Hero Section Requirements

- Placed as the first section inside <main>
- Includes a headline and subheading
- Includes a call-to-action (CTA) button
- Supports future background image or gradient via CSS
- Optional scroll indicator (decorative only)

## Accessibility Considerations

- Use semantic <section>
- Proper heading structure
- CTA implemented using a native <a> or <button>
- Scroll indicator marked as decorative

## Acceptance Criteria

- Hero section exists in index.html
- Content is semantic and accessible
- Page structure remains valid and logical
