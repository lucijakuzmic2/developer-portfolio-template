# Plan 3 — Set up index.html with semantic skeleton

## Goal

Create the base HTML structure using semantic elements to provide a clear, accessible layout foundation for the portfolio template.

## Why

- Semantic HTML improves accessibility and SEO
- Provides a logical structure for screen readers
- Creates a maintainable layout foundation for styling and scripting

## Scope

Files to create:

- index.html

## Semantic Structure

The document will include:

- <header> for site header and navigation
- <nav> for primary navigation links
- <main> for primary page content
- <section> elements for logical content grouping
- <footer> for footer information

## Accessibility Considerations

- Use semantic elements instead of generic <div>s
- Include a skip-to-content link
- Ensure correct document outline with headings

## Acceptance Criteria

- index.html exists at project root
- Uses semantic HTML5 elements appropriately
- Page is valid HTML and renders in browser
